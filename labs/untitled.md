# 3. Основные команды терминала

| Команда | Действие |
|---------|----------|
| `pwd` | показать текущую папку |
| `ls` | показать содержимое папки |
| `cd` | перейти в другую папку |
| `mkdir` | создать папку |
| `rm` | удалить файл |
| `cp` | скопировать файл |
| `mv` | переместить или переименовать |

---

# 4. Запуск программ

- `firefox` — если программа в `PATH`
- `./myprogram` — запуск из текущей папки
- `Ctrl + C` — прервать выполнение
- `Ctrl + Z` — приостановить выполнение
- `gedit &` — запустить в фоновом режиме
- `jobs` — посмотреть фоновые задачи
- `fg` — вернуть задачу на передний план

---

# 5. Перенаправление ввода-вывода

- `>` — перенаправить вывод в файл (перезапись)
- `>>` — перенаправить вывод в файл (добавление)
- `<` — взять ввод из файла
- `|` — конвейер (передать вывод одной команды на ввод другой)

Пример: `cat file.txt | grep "error" | wc -l`

---

# 6. Работа с архивами

Создание архива:
`tar -czvf archive.tar.gz папка/`

Распаковка архива:
`tar -xzvf archive.tar.gz`

Ключи:
- `c` — создать
- `x` — извлечь
- `z` — сжать через gzip
- `v` — подробный вывод
- `f` — указать имя файла

---

# 7. Поиск файлов и текста

Поиск файлов — `find`:
`find . -name "*.txt"`

Поиск текста внутри файлов — `grep`:
`grep "слово" file.txt`
`grep -r "ошибка" ./` — рекурсивно
`grep -i "hello" file.txt` — без учёта регистра

---

# 8. Удалённый доступ по SSH

Подключение к серверу:
`ssh user@server.com`
`ssh -p 2222 user@server.com`

Копирование файлов через `scp`:
`scp file.txt user@server:~/`
`scp user@server:~/data.txt ./`

Выход: `exit`

---

# 9. Текстовый редактор vim

Режимы:
- Normal (Esc)
- Insert (i, a, o)
- Command-line (:)

Основные команды:
- `:w` — сохранить
- `:q` — выйти
- `:wq` или `ZZ` — сохранить и выйти
- `:q!` — выйти без сохранения
- `dd` — удалить строку
- `yy` — скопировать строку
- `p` — вставить
- `/слово` — поиск

# 10. Bash-скрипты: основы

Структура скрипта:
`#!/bin/bash`
`echo "Hello, world!"`

Сделать исполняемым:
`chmod +x script.sh`

Запустить:
`./script.sh`

Переменные:
`name="Linux"`
`echo $name`

---

# 11. Ветвления и циклы в bash

Условие if:
`if [ -f "file.txt" ]; then`
    `echo "Файл существует"`
`else`
    `echo "Файл не найден"`
`fi`

Цикл for:
`for i in 1 2 3 4 5; do`
    `echo "Number: $i"`
`done`

---

# 12. Продвинутая обработка текста

`sed` — замена текста:
`sed 's/old/new/g' file.txt` — вывод на экран
`sed -i 's/old/new/g' file.txt` — изменить файл

`awk` — работа с колонками:
`awk '{print $1}' file.txt` — первая колонка
`awk '{sum+=$2} END {print sum}'` — сумма по второй колонке

# 13. Построение графиков в gnuplot

Входной файл (две колонки):
`1 2.3`
`2 4.1`
`3 5.8`

Команды gnuplot:
`plot "data.txt" with linespoints`
`set xlabel "X axis"`
`set ylabel "Y axis"`
`set title "My graph"`
`set terminal png`
`set output "graph.png"`
`replot`

# 14. Менеджер терминалов tmux

Зачем нужен:
- Несколько окон в одном терминале
- Сессии не закрываются при обрыве SSH

Основные команды:
`tmux new -s mysession` — создать сессию
`Ctrl+B` затем `D` — отключиться от сессии
`tmux attach -t mysession` — подключиться снова
`Ctrl+B` затем `%` — разделить окно по вертикали
`Ctrl+B` затем `"` — разделить окно по горизонтали
